# Historical material

These configurations and shell recipes document 0.1-era research experiments. They retain original run paths and obsolete command names for provenance; use the portable recipes under `examples/` with 0.2.

The [research report](../literature_review.md), its references/figures, and the inventories under `sanity_checks/` preserve the research context. Historical corpus counts and model experiments describe those earlier runs, not outputs promised by a new execution.

Private or ignored local configs are not included in this archive. Existing corpora and run directories are retained locally and excluded from release distributions.
